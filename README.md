# Multi-Agent Content Generator

AI-powered application for generating SEO-oriented articles using a multi-agent architecture with CrewAI and Google Gemini.

## Features

* Multi-agent workflow: Planner, Writer, and Editor
* AI-generated and SEO-oriented articles
* Streamlit web interface
* Google Gemini integration

## Technologies

Python, CrewAI, Google Gemini, Streamlit

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Run the application:

```bash
streamlit run app.py
```
